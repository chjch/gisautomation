# ArcGIS API for Python

## Learning Objectives

Upon completion of this module, you should be able to:

- Understand features of the ArcGIS API for Python
- Plot spatial data on a map inside Python Notebook
- Use and process the Spatially Enabled DataFrame (SEDF)
- Perform GeoEnrichment in any given area
